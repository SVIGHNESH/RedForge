# Requirements Traceability Matrix

Generated by `make rtm` (`scripts/tasks/rtm`) from the GitHub issues and pull requests of `SVIGHNESH/RedForge`.
Do not edit by hand: rerun the generator after issues, assignees or PRs change.
Dependencies come from the `Blocked by:` line of each issue, which `scripts/tasks/sync-issues.sh` writes from the task files.

## How to read it

- **Requirement** is the proposal item (M1 to M11 Must, S1 to S5 Stretch) and the synopsis objective it serves (MASTER-PLAN Section 1.1).
- **Blocked by** lists every issue that must merge first, with its owner, so it shows whose work is holding a task.
A ticked blocker (`#7 ✓`) is closed.
- **Unblocks** is the reverse edge: the issues waiting on this one.
- **Status** is one of: Done (issue closed), In review (open PR, with the PR it is stacked on), Ready (every blocker closed), or Blocked (with the owners of the open blockers).
- **Acceptance** links the task file, whose Acceptance checklist is the definition of done.
